# Worldmaker

A map editor for made-up places that looks and works like a street map. It opens on
an example city, Port Ellery, which you can edit or replace with a blank map.

Open `index.html` in any browser. It is one file and needs no build step or install.

- **Road**: highways, main roads, streets, footpaths and railways. Roads snap together and connect where they meet or cross.
- **River**: rivers, canals and streams.
- **Area**: parks, lakes and seas, forests, beaches, plazas, islands, and buildings of any shape.
- **Building**: drag a rectangle to make a building.
- **Place**: pins for landmarks, food, shops, hotels, schools, hospitals, nature, transit and homes, each with notes.
- **Label**: names for districts and towns.
- **Search**, **directions** for driving or walking with turn-by-turn steps along your own roads, and undo/redo.

Your map saves automatically in the browser. Use *Copy map code* or *Download .json* in the
menu to back it up, and *Open file* or paste the code to load it again.
